# Mondrian Art – CSS Grid Layout

## About the Project

This project is a recreation of a Mondrian-inspired abstract artwork using HTML and CSS Grid. It demonstrates how to create geometric compositions with different sizes, colors, and positions.

The layout is inspired by the artistic style of Piet Mondrian, featuring bold black grid lines and a combination of primary colors.

## Built With

- HTML5
- CSS3
- CSS Grid
- Flexbox

## Features

- Grid-based layout using CSS Grid.
- Geometric shapes with different dimensions.
- Primary colors: red, blue, and yellow.
- Black grid lines and off-white backgrounds.
- Centered artwork using Flexbox.

## What I Learned

- Creating layouts with `display: grid`.
- Defining rows and columns with `grid-template-columns` and `grid-template-rows`.
- Controlling item placement using `grid-column`, `grid-row`, and `grid-area`.
- Using gaps to create grid lines.
- Combining CSS Grid and Flexbox.

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
